# CARBON 2.0 — Premium Fitness E-commerce & Admin Platform

منصة تجارة إلكترونية رياضية واحترافية متكاملة لعلامة **Carbon Group Nutrition**، مبنية بأحدث معايير الـ UI/UX وMotion والأداء والتجارة الإلكترونية الحقيقية.

- **الموقع المنشور (GitHub Pages):** [https://najf8.github.io/carbon/](https://najf8.github.io/carbon/)
- **Instagram الرسمي:** [@carbon__group](https://www.instagram.com/carbon__group/)

## 🚀 المميزات الرئيسية

### 1. واجهة المتجر (Storefront)
- **هوية بصرية رياضية حقيقية (Carbon Dark & Neon Emerald):** مستخرجة بدقة من شعار وهوية Carbon الأصلية بدون تأثيرات SaaS اصطناعية.
- **عرض سينمائي 2.5D في الـ Hero:** محاكاة ثلاثية الأبعاد خفيفة الوزن للمنتجات تتفاعل مع حركة الماوس والبارالاكس بدون استهلاك معالج الرسوميات (WebGL-free).
- **نظام حركة متقن (Motion System):** تأثيرات دخول سلسة، تكبير وتفاصيل عند التمرير، وأنيميشن نقل المنتج مباشرة إلى السلة (`fly-to-cart`).
- **أقسام المتجر الـ 5 الأساسية:**
  1. 🥤 **البروتين (Protein):** واي بروتين، جينرات الضخامة.
  2. ⚡ **الكرياتين (Creatine):** كرياتين مونوهيدرات ميكرونايزد، مكملات الطاقة.
  3. 🏋️ **المستلزمات (Accessories):** شيكرات رياضية 750 مل، أربطة معصم.
  4. 👕 **الملابس (Clothing):** تيشيرتات أوفرسايز وشورتات تدريب.
  5. 🔥 **العروض (Offers):** صفحة ومنتجات الخصومات الحية.
- **بطاقات المنتجات الاحترافية (Product Cards):** تبديل الصور عند التمرير، شارات العروض والتخفيض ونفاد المخزون، السعر القديم والجديد، التقييم، المفضلة، والنظرة السريعة (Quick View).
- **صفحة تفاصيل المنتج الكاملة (PDP):** معرض صور تفاعلي مع تكبير (Zoom)، محدد المقاسات والألوان، الفوائد بنقاط واضحة، جدول المواصفات، والمنتجات ذات الصلة.
- **بحث حي فوري (Live Search Overlay):** بحث ذكي بالأحرف مع نتائج مباشرة، عمليات البحث الأخيرة، والأكثر بحثاً.
- **سلة مشتريات متطورة (Cart Drawer & Page):** حساب التخفيضات والكوبونات وتكلفة التوصيل، وإتمام الطلب المباشر عبر رسالة واتساب منظمة ومفصلة.
- **نظام كوبونات وعروض ذكي:** يدعم الخصم النسبي والمبلغ الثابت، مع فحص الحد الأدنى وتاريخ الصلاحية.
- **مساعد كاربون الذكي (Chat Assistant):** ردود سريعة ذكية للتوجيه للأقسام والعروض وتحويل الزبائن للواتساب مباشرة.
- **ثنائي اللغة والاتجاه (Bilingual & Full RTL/LTR):**
  - 🇮🇶 العربية (IBM Plex Sans Arabic — RTL)
  - 🇬🇧 English (Arial — LTR)
- **دعم المظهرين (Light & Dark Mode):** تصميم مستقل لكل مظهر بدون قلب ألوان عشوائي.

### 2. لوحة التحكم الكاملة (CARBON ADMIN CMS)
لوحة تحكم إدارية متكاملة تتيح للمدير إدارة المتجر بدون تعديل سطر برمجي واحد:
- **لوحة المعلومات (Dashboard):** إحصائيات المخزون، المنتجات المفعّلة، المنتجات منخفضة المخزون، وتوزيع المنتجات حسب القسم برسم بياني حقيقي.
- **إدارة المنتجات (Products Management):** إضافة وتعديل وحذف وتكرار المنتجات، رفع الصور وترتيبها واختيار الصورة الرئيسية، تحديد المقاسات والألوان، وتعديل الأسعار والخصومات السريعة.
- **إدارة الأقسام (Categories):** ترتيب الأقسام، رفع صورها، وتفعيلها أو تعطيلها.
- **إدارة العلامات التجارية (Brands):** إدارة الشركاء والعلامات العالمية.
- **إدارة العروض وحملات التخفيض (Offers):** جدولة العروض مع تواريخ بداية ونهاية وحساب الخصم تلقائياً.
- **إدارة الكوبونات (Coupons):** إنشاء أكواد ترويجية مثل `CARBON10` وتحديد حدود الاستخدام والحد الأدنى للطلب.
- **منشئ الصفحة الرئيسية (Homepage Builder):** إعادة ترتيب أقسام الصفحة الرئيسية بالسحب أو الأزرار، وتعديل الـ Hero والنصوص والأزرار والخلفيات فورياً.
- **إدارة البانرات الإعلانية (Banners):** رفع وتعيين البانرات للحاسوب والجوال مع الروابط.
- **إعدادات المتجر والمحادثة (Settings & Chat):** ضبط أرقام الواتساب ورسوم التوصيل والردود السريعة للمساعد الذكي.

## 🔒 بنية الأمان ومصادقة لوحة الإدارة

تطبيقاً لقواعد الأمان الصارمة:
1. **GitHub Pages (نشر ساكن):** يعمل كواجهة متجر سريعة وآمنة تقرأ البيانات من `public/data/catalog.json`.
2. **وضع المعاينة المحلي (Local Preview):** متاح فقط في بيئة التطوير `npm run dev` لتجربة لوحة التحكم والتعديل في ذاكرة المتصفح دون وهم أمني.
3. **الربط مع Firebase (للإنتاج):**
   - يدعم مصادقة Google البريد الإلكتروني مع كلمة المرور.
   - التحقق من صلاحيات المدير عبر قاعدة البيانات `firestore.rules` وتوثيق البريد.

## 📦 مسارات الصور وملفات الـ Assets

- `public/assets/brand/`: شعار كاربون المفرغ، أيقونة المتصفح، وصورة المساعد.
- `public/assets/banners/`: صور البانرات والـ Hero بدقة WebP محسنة.

- جميع المسارات تستخدم دالة `asset()` المتوافقة 100% مع مسار GitHub Pages (`/carbon/`).
